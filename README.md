## 🏗️ 6. Portfolio Website Architecture

The portfolio is structured as a dual-language (English / French) responsive Single Page Application (SPA):

- **Main Entry Points**:
  - English: `index.html` (root)
  - French: `fr/index.html` (`/fr/`)
- **Styling**: Tailwind CSS (CDN), custom CSS (`assets/css/style.css`), Space Grotesk & Inter typography.
- **Dynamic JavaScript Logic**: `assets/js/main.js`
  - Automatic language detection based on URL path (`/fr/`) and document `lang` attribute.

  - Features asynchronous skeleton loading, interactive modal popups, and a full-screen image gallery viewer.
